# Security Policy

## Supported versions

Transmark is pre-alpha. Security fixes are applied to the latest release only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting form:

https://github.com/fissible/transmark/security/advisories/new

Include reproduction steps, affected versions, and the potential impact. You
can expect an acknowledgement within five business days. We will coordinate
disclosure and credit with you before publishing an advisory or fix.
